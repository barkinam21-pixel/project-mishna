## הרכבת סרט ניסיון פרטי מחומרים אמיתיים — מסלול הנדסי

[PR #6 — מנוע ההרכבה מוזג ואומת ב־CI](https://github.com/barkinam21-pixel/project-mishna/pull/6), כולל [בדיקת FFmpeg מעשית על חומרי TEST מלאכותיים בלבד](https://github.com/barkinam21-pixel/project-mishna/actions/runs/41263081764), מוסיף אפשרות להרכיב סרט 75 שניות **רק אחרי** שיסופקו 16 איורים מקוריים נפרדים, קובצי דיבור עברי אמיתיים וכתוביות שנבדקו. עדיין אין במאגר נכסים כאלה; המנוע אינו מייצר אותם.

- `python -m tools.private_proof_assembler` — **בדיקת מוכנות לקריאה בלבד**, ללא תמונות, קול, רינדור, תשלום או שינוי אישורים; פלט צפוי כעת `BLOCKED_MISSING_REAL_MEDIA`.
- קובץ הרישום הזמני: [private-proof-assets.example.json](episodes/berakhot-01-01/private-proof-assets.example.json). לכל איור/קובץ WAV עתידי יירשמו מקור, רישיון, בדיקת זכויות, hash ואישור לשימוש **פרטי בלבד**. הדוגמה בכוונה ריקה; SH01 אינו נכס מאושר.
- **טיוטת כתוביות וקריינות פרטית מוכנה לבדיקות:** [16 קטעים עם זמני פריימים וייחוס מקור](episodes/berakhot-01-01/private-proof-caption-draft.json) — אלה פרפרזות והמחזה, **לא** הקלטה, לא טקסט משנה נעול ולא אישור פרסום. [תיק מודלי קול ורישיונות](episodes/berakhot-01-01/source-dossier.md) נמצא במחקר, ללא קול שהופק.
- `--render-private` חסום כל עוד חומר אמיתי, טקסט כתוביות בדוק או הרשאת ניסיון פרטית חסרים. כשיתאפשר, FFmpeg ירכיב H.264 + AAC ו־SRT/VTT/ASS כקבצים מקומיים. אי אפשר להפיק זאת דרך GitHub Actions ללא העלאת נכסים ממשיים.
- `private_preview_authorized` בדוגמה **אינו** אישור תורני, קול, זכויות לציבור או פרסום. כל הדגלים במניפסט הראשי נשארים `false`. אפילו בדיקת FFmpeg מצליחה על גוונים/צלילי־בדיקה היא **בדיקה הנדסית בלבד**, לא ״סרט״.
- **ייצוא חכם מהמחברת:** ZIP כולל רק איורים שנבחרו להרצה הנוכחית, גיליון ביקורת ומידע אימות; תמונות ישנות או `superseded` נשמרות במחברת אך לא מועברות בטעות לחבילת הביקורת. זה מונע פסילת ZIP תקין בגלל ניסוי ישן ומקטין העברת נתונים בטלפון.
- **קליטת איורים שנוצרו ב־Colab, בלי מילוי JSON ידני:** `python -m tools.colab_image_intake path/to/mishnah-free-image-trials.zip` בודק במצב קריאה בלבד את נתוני המקור, hash, PNG, גרסת הפרומפט, נתוני המודל ואיסור הוצאה. `--stage` מעתיק קבצים תקינים רק לתיקיית `private-media/` הפרטית והלא־מנוהלת ב־Git, ומפיק `review-candidate-*.json` עם רשימת איורים לביקורת. **חדש:** מחברת Colab מפיקה עכשיו גם `review-contact-sheet.jpg` — גיליון אחד של כל האיורים, עם תוויות `UNAPPROVED`, שאפשר לצפות בו בטלפון. הכלי קולט אותו בנפרד כחומר תצוגה בלבד ולא סופר אותו כאיור נוסף. המודל הכבד נטען רק אם נדרשת יצירה חדשה ולא כשהכול מאומת במטמון. **אין** העלאה לרשת, זיהוי איכות אמנותית, אישור זכויות/מקורות, הפקת קול או שינוי דגלי האישור; SH01 שנדחה נותר בחוץ. זהו שלב טכני עתידי **רק לאחר שיש ZIP אמיתי**; בדיקות היחידה משתמשות בתמונות־דמה בלבד.


- **ניסיון SH09 אמיתי והפקת לקחים (1.11.2026):** ב־ZIP ששלח המשתמש נמצאו PNG אמיתי 1024×576, התאמות SHA-256 ליומן ולמפרט, SDXL על Tesla T4 (משך מדווח 50.7 שניות). האיור יפה בסגנון הציורי, אך מראה אדם אחד בנוף מואר במקום שני גברים *כדמויות המחזה* בחצר בית בלילה. ראיות טכניות ללא התמונה הפרטית נשמרו ב-[trials.json](episodes/berakhot-01-01/trials.json), והאיור **לא התקבל** לנכסי הסרט. נחשף גורם סביר: פרומפט ישן בן 139 מילים שהתחיל ב־72 מילים של סגנון לפני תיאור השוט. הקוד שונה כך שהפעולה/קומפוזיציה נשלחות ל־`prompt`, וסגנון האיור הציורי ל־`prompt_2` של SDXL; לפני רינדור יש בדיקת אורך לכל CLIP ואימות SHA לשני הערוצים. **השיפור אינו הוכחה לתוצאה חזותית חדשה עד להרצת GPU נוספת.**

Workflow חדש נעשה זמין להפעלה ידנית רק לאחר מיזוג; ה־PR מפעיל אותו לבדיקה אוטומטית.

ההרצה שומרת `report.json`, `report.md` ויומן שימוש עם hashes כ־artifact בשם `cloud-proof-report-NOT-A-FILM`. הצלחת הבדיקה אינה הצלחת הפקה. אין יצירה, תשלום או העלאת מדיה. בענן פרטי עם נכסים שנבדקו, פקודה אחת `python -m tools.cloud_proof --assets <registry.json> --render-private` משתמשת במנוע הקיים, בודקת את האישורים ומפענחת את הפלט במלואו. הסרט והכתוביות נשמרים מקומית בלבד; אין כאן חיבור אוטומטי לאחסון מדיה פרטי או מנגנון סינתזת קול. כל שינוי ברישום מחייב ניסיון חדש; היומן מצטבר ואין שימוש בסרט ישן כתוצאה חדשה.


**סבב איכות לאחר האזנת בר:** קול MMS הקודם נדחה ונחסם לפי hash. מנוע ההרכבה מחובר כעת למצלמה תת־פיקסלית הקיימת ולכמה כתוביות בכל שוט. הופקה תצוגת עריכה פרטית בת 12 שניות משני איורים מקוריים: תנועה אופקית ואחריה התקרבות. **ללא קריינות — חסם הקול עדיין פתוח**, לא הצלחת הפקת סרט לימודי. ראיות ומגבלות: [דוח הסבב](docs/evidence/issue-37/quality-round-report.json), [מסירת מצב](docs/session-handoff.md). PR #38 נשאר ללא מיזוג; אין שינוי באישורי מקור/זכויות/פרסום.
