# אולפן המשנה | Mishnah Film Studio

מערכת ראשונית לניהול הפקת סדרה קולנועית מאוירת על המשנה. מתחילים **ברכות א׳, א׳**.

**מצב נוכחי: תכנון ובדיקת בטיחות בלבד. עדיין אין יצירת תמונות/וידאו או קריינות.**

## מה כבר אוטומטי

- בעת עדכון המאגר, GitHub Actions מריץ בדיקות ומפיק דוח `preflight-report` להורדה (ב-Actions).
- `episodes/berakhot-01-01/manifest.json` הוא מקור האמת של הפרק.
- `tools/studio.py` בודק את זהות המשנה, מסלול אימות המקורות, אישורים, תקציב, תמונות, סצנות, כתוביות וזכויות.
- שגיאה טכנית גורמת לכישלון הבדיקה. חסר של אישור תורני / תסריט / חומרי הפקה נותן מצב `BLOCKED_AS_DESIGNED` — זהו מצב צפוי ומכוון, **לא אישור להפקה**.
- אף כלי כאן אינו פונה למודל בתשלום, יוצר תמונה, מעלה סרט או מפעיל שירות חיצוני. התקציב הנוכחי: **$0** בשירותי יצירה חיצוניים; שימוש ב-GitHub Actions עשוי להיות כפוף למכסות התוכנית שלך.

## תהליך עבודה מתוכנן

1. אימות נוסח המשנה מול שני מקורות; תיעוד פירושים, היסטוריה, ורישיונות.
2. כתיבת תסריט עשיר וסטוריבורד; אבחנה בין מקור, פירוש והמחזה.
3. אישור כיוון חזותי וקולות; יצירת תמונות מקוריות עקביות.
4. הנפשת מספר מצומצם של שוטים, קריינות, וכתוביות בעברית.
5. עריכת MP4 אוטומטית, בדיקות איכות אנושיות, ואישור לפני פרסום.

**השלב הבא:** תיק מקורות מאומת לברכות א׳, א׳. לא נוצרה אנימציה; אין התחייבות לתוצאות AI טרם מבחן איכות.

## פקודה למפתחים (אין צורך להריץ בעצמך)

```bash
python -m unittest discover -s tests -v
python tools/studio.py episodes/berakhot-01-01/manifest.json --output build/preflight.json
```

## כלל זכויות ומקורות

שני קישורים במניפסט הם **מועמדים לבדיקה**, לא טקסטים שאומתו או שרישיונותיהם אושרו. אין לפרסם תוכן תורני בלי בדיקת אדם בעל ידע תורני, בדיקת רישיונות, ובקרת איכות של עברית, סאונד, דמויות ורצף.
