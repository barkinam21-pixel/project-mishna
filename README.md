## הרכבת סרט ניסיון פרטי מחומרים אמיתיים — מסלול הנדסי

[PR #6 — מנוע ההרכבה מוזג ואומת ב־CI](https://github.com/barkinam21-pixel/project-mishna/pull/6), כולל [בדיקת FFmpeg מעשית על חומרי TEST מלאכותיים בלבד](https://github.com/barkinam21-pixel/project-mishna/actions/runs/41263081764), מוסיף אפשרות להרכיב סרט 75 שניות **רק אחרי** שיסופקו 16 איורים מקוריים נפרדים, קובצי דיבור עברי אמיתיים וכתוביות שנבדקו. עדיין אין במאגר נכסים כאלה; המנוע אינו מייצר אותם.

- `python -m tools.private_proof_assembler` — **בדיקת מוכנות לקריאה בלבד**, ללא תמונות, קול, רינדור, תשלום או שינוי אישורים; פלט צפוי כעת `BLOCKED_MISSING_REAL_MEDIA`.
- קובץ הרישום הזמני: [private-proof-assets.example.json](episodes/berakhot-01-01/private-proof-assets.example.json). לכל איור/קובץ WAV עתידי יירשמו מקור, רישיון, בדיקת זכויות, hash ואישור לשימוש **פרטי בלבד**. הדוגמה בכוונה ריקה; SH01 אינו נכס מאושר.
- **טיוטת כתוביות וקריינות פרטית מוכנה לבדיקות:** [16 קטעים עם זמני פריימים וייחוס מקור](episodes/berakhot-01-01/private-proof-caption-draft.json) — אלה פרפרזות והמחזה, **לא** הקלטה, לא טקסט משנה נעול ולא אישור פרסום. [תיק מודלי קול ורישיונות](episodes/berakhot-01-01/source-dossier.md) נמצא במחקר, ללא קול שהופק.
- `--render-private` חסום כל עוד חומר אמיתי, טקסט כתוביות בדוק או הרשאת ניסיון פרטית חסרים. כשיתאפשר, FFmpeg ירכיב H.264 + AAC ו־SRT/VTT/ASS כקבצים מקומיים. אי אפשר להפיק זאת דרך GitHub Actions ללא העלאת נכסים ממשיים.
- `private_preview_authorized` בדוגמה **אינו** אישור תורני, קול, זכויות לציבור או פרסום. כל הדגלים במניפסט הראשי נשארים `false`. אפילו בדיקת FFmpeg מצליחה על גוונים/צלילי־בדיקה היא **בדיקה הנדסית בלבד**, לא ״סרט״.

## החלטות שלא משנים אוטומטית
- הצגה רצינית, חמה, קולנועית ומבוססת על **איורים מקוריים סטטיים**.
- כרגע **אין** אנימציית פנים/גוף; מצלמה ופרלקסה מתונה בעריכה בלבד.
- אין להחליף איור מקורי ברצף קרופים חוזרים.
- עובדות המקור נפרדות מפירוש, תוספת היסטורית והמחזה.
- מקור תורה, דמויות, קול, סגנון, עלות ופרק קצר טעונים אישור בשלבים.
- **אסור** להפעיל יצירה בתשלום, לשכפל מדיה מוגנת, או לפרסם לפני שערי אישור.
- הקבצים אינם סרט, אינם מנוע פעיל, ואינם נכסים שהופקו.

## משימה הבאה
**כעת, לפי בקשת בר (1.11.2026):** בלי להעמיס חיפוש רב/בודק תורני חיצוני או טפסים על בר. המפיק מבצע בעצמו [הצלבת מקורות, פירושים והגייה](episodes/berakhot-01-01/source-dossier.md), מכין טיוטות קולנועיות לא־נעולות (ראו [תסריט פרק 1 שתוקן](scripts/episode-01-before-dawn.md)) ומברר רישוי לכל נכס. ניתן להכין **ניסוי storyreel פרטי** על בסיס חומרים מקוריים ומותרים *אם יינתן אישור מסוים לסגנון/קול*, בלי להציג אותו כסרט שאושר ובלי להפעיל שירות בתשלום. **לפני כל פרסום לציבור/מסחר**, דרישות ביקורת תורנית אנושית, זכויות, איכות קול ופרסום נשארות בתוקף; שום אישור במניפסט אינו משתנה. יעד ביניים: סרט ניסיון אמיתי של 60–90 שניות (איורים מקוריים + קריינות + כתוביות), לא וידאו של כרטיסי בדיקה.

**בדיקה:** בקובץ ה-JSON קיימים 14 שוטים ייחודיים; אורכי הטיוטה מסתכמים ב-121 שניות, ולשיחת הבנים נדרש איור תגובה מקורי נוסף. אין מנוע רינדור מופעל, אין תוצר וידאו, ואין חיוב API שבוצע במסגרת כתיבת המסמכים.
