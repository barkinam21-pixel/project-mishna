# אולפן המשנה | Mishnah Film Studio

**מטרה:** סדרת סרטים קולנועיים מאוירים על המשנה, בסגנון ריאליסטי־מצויר, רציני ונגיש, בהתחלה עם ברכות א׳, א׳.

## מצב נכון לעכשיו

✅ GitHub Actions מריץ **שני מסלולים במקביל**: בדיקות Python + preflight, והשוואת **שלוש מהדורות נפרדות** של משנה ברכות א׳, א׳ ב-Sefaria API (בלי שירותי יצירה בתשלום).  
✅ קיים מניפסט פרק עם בקרת תקציב ואישורים.  
✅ [תיק המקורות לברכות א׳, א׳](episodes/berakhot-01-01/source-dossier.md) כולל השוואת טקסט ממשית מול **תורת אמת, דפוס וילנה וכתב יד קאופמן**, והכרה בגרסאות **חיוב/היתר**; אומתו גם שינויי מספור מול מכון ממרא.
✅ הוספנו גם זיהוי מדויק של **כתב יד קאופמן A50, דף 2א**, אזהרה מפני שימוש בלתי מורשה בצילומו, ו[דף מסירה קצר לביקורת תורנית](episodes/berakhot-01-01/torah-review-handoff.md).  
✅ קיימת [תוכנית חיבור מנועי ההפקה](docs/production-architecture.md): GitHub orchestration, FLUX/ComfyUI, Wan/LTX, עברית, FFmpeg, ואישורי הפקה.
✅ נבדקו [חלופות זולות ל-Higgsfield](docs/low-cost-video-alternatives.md): Wan2.2, HunyuanVideo-1.5, FramePack ו-LTX, כולל GPU, רישוי ועלויות ענן אפשריות. **לא הותקן ולא חויב שום מנוע יצירה.**
✅ קיימת כעת **[טיוטת תסריט ל-75 שניות](episodes/berakhot-01-01/literary-draft.md)**, [מפת מקור־סצנה](episodes/berakhot-01-01/source-to-scene-map.md) ו[תוכנית צילום מובנית](episodes/berakhot-01-01/proof-blueprint.json): חמש סצנות, 16 שוטים, 1,800 פריימים. **לא אושרו להפקה**.
✅ GitHub Actions בודק גם רציפות פריימים, תיאורי מקורות, תכנון מספר איורים, ומונע מצג שווא של אישור/נכסים שלא קיימים.
✅ [תנ״ך חזותי לכיוון האמנותי](episodes/berakhot-01-01/visual-bible.md) מוכן להחלטה של בר. [מנוע כתוביות עבריות](tools/hebrew_captions.py) מייצא SRT/VTT/ASS מתזמון פריימים ונבדק על מקרי RTL, אבל **מסרב להפיק כתוביות לפרק לפני נעילת נוסח וביקורת תורנית**. [מניפסט כתוביות](episodes/berakhot-01-01/hebrew-caption-master.json) ריק במתכוון.

⏳ עדיין לא נעשו: נעילת נוסח מדויק במהדורה שמותר להשתמש בה, אישור אנושי תורני, **אישור תסריט הטיוטה**, עיצוב דמויות, קריינות או אנימציה. **אין כרגע סרט מוגמר או מנוע AI מחובר.**

## איך זה יעבוד בלי מחשב חזק

GitHub שומר קבצים והחלטות, ומפעיל בדיקות אוטומטיות. לאחר אישורים, שירות תמונות/GPU חיצוני יפיק *תמונות מקוריות* ואנימציה נבחרת, ו-FFmpeg ירכיב MP4 בענן. אין צורך בהתקנת כלים כבדים במחשב של בר.

**ההמלצה החסכונית:** רוב הסרט = איורים מקוריים מאושרים עם עריכת FFmpeg; אנימציה גנרטיבית רק לשוטים נבחרים. **GitHub Actions סטנדרטי אינו מכיל GPU ליצירת וידאו AI.** תשתית GPU נפרדת תיבדק רק אחרי מבחן איכות ותמחור. לא נכנס שירות בתשלום ללא אישור מפורש.

## הרצה ותוצאות

[GitHub Actions — בדיקת האולפן](https://github.com/barkinam21-pixel/project-mishna/actions/workflows/studio-check.yml)

כל דחיפה ל-main מפעילה בדיקות ומייצרת דוחות `preflight-report`, `editorial-plan-review` ו-`sefaria-three-edition-audit` (כשהריצה מסתיימת). החיבור לספריא קורא מידע בלבד, שומר מטא-נתונים וגיבוב SHA-256 — ואינו מסמן מקור כמאושר אוטומטית. מצב `BLOCKED_AS_DESIGNED` פירושו שהתוכנה פעלה אך **הפקה/פרסום חסומים** בגלל מקורות, אישורים, זכויות או נכסים חסרים. אין לבלבל הצלחת בדיקות עם סרט מאומת. בדיקת המקורות גם **מסרבת לעבור אם גרסת "חייבין/מותרין" חורגת מהעדויות המתועדות**, ומחייבת בדיקה אנושית במקום שינוי שקט.

## הצעד הבא

אישור כיוון חזותי לצורך **איור מבחן יחיד בלבד**, וביקורת על טיוטת התסריט ומפת הסצנות, לצד נעילה מנומקת של מהדורה מתאימה (וילנה 1913 היא מועמדת ראשונה, מסומנת Public Domain בספריא), בדיקת הווריאנט בכתב יד וביקורת תורנית אנושית. אחר כך אפשר להכין תסריט, מפה חזותית ודוגמת סרט פרטית באורך 60–90 שניות.

## עקרונות

- לשון המשנה, פירוש המפרשים והמחזה מסומנים בנפרד.
- אין הצגת מפגש היסטורי בין תנאים על סמך ציטוט דעות סמוכות בלבד.
- לפחות 4–7 איורים מקוריים לסצנה דרמטית; תמונה אחת עם זום אינה אנימציה קולנועית.
- אין כתיבה של כתוביות לתוך תמונה גנרטיבית — כתוביות עבריות ייבנו בנפרד.
- אין שימוש בציטוטים או בתמונות מתוך מהדורות מוגנות בלי הרשאה.
- אף פעולה אוטומטית לא רשאית להוציא כסף או לפרסם בלי אישור.
