Mishnah Private Drive

Mishnah Private Drive is a personal, non-commercial utility that allows its owner to authorize limited access to specifically selected Google Drive files for a private educational media production workflow.

The app requests the Google Drive drive.file scope and requires the owner to select the files explicitly. It does not provide a public file browser or publish the contents of those files.

Access is intended for the account owner only. This informational website does not collect user information.
