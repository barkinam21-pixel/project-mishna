Privacy Policy

Last updated: 13 November 2026

Mishnah Private Drive is a private utility operated for its owner's personal educational media project. It is not a public service.

Information accessed

With the owner's consent, the app requests the drive.file permission to access only Google Drive files that the owner explicitly selects for the app. It may read file metadata and contents to validate private project assets. It does not request access to all Google Drive files.

Use and storage

Access tokens and refresh tokens are used to authenticate the private automation. The intended workflow stores the authorization credentials as an encrypted GitHub Actions secret; credentials are not displayed on this website. Selected file contents may be processed temporarily by the private automation for validation. This website does not collect analytics or accept uploads.

Sharing

The app is not intended to share selected files with the public or sell personal information. Third-party infrastructure providers involved in authentication, storage and automation may process information to provide their services.

Control

The owner can revoke access at any time in Google Account settings and remove the associated GitHub Actions secret. Revocation stops future authorized access.

Contact

For privacy inquiries, contact the project maintainer through the repository's GitHub Issues interface. Do not post personal information or credentials publicly.
