# חוזה עצמאות ההפקה — בלי תלות ב-Codex (8.11.2026)

**מעמד:** דרישת הנדסה מחייבת; זהו מסמך החלטה, **לא** הצהרה שהאוטומציה החדשה כבר קיימת. Codex הוא מתכנת אפשרי, לא רכיב Runtime. חוזה זה חל על הפקת איורים וקריינות ועל סרטון ניסיון פרטי, ולא עוקף אישורים/זכויות/ביקורת תורנית.

## מה כבר קיים, ואין לכתוב מחדש

- `tools/comfy_scene_images.py`: מרכיב גרף ComfyUI מנתוני `episodes/berakhot-01-01/comfy-opening-images.json`, בודק הרשאות יצירה, שומר state/cache ויכול להמשיך משימה שתלויה בתור. בדיקת HTTP עם PNG פיקטיבי איננה הוכחה שהמודל יצר איור. הנתיב למחשב GPU אמיתי עדיין לא הופעל בהצלחה בתנאים מאומתים.
- `tools/comfy_runtime.py`: בודק אם ComfyUI ו-GPU זמינים בלי לשלוח משימת יצירה. ניתן להחליף endpoint פרטי בלי שינוי התסריט או גרף הבימוי.
- `tools/scene_pack_preflight.py`: מחזיר מצב שבעת השוטים והחסמים בלי קריאות לספק.
- `tools/scene_review_board.py`: מפיק לוח ביקורת פרטי רק מנכסים מקומיים שעברו בדיקת checksum; בהיעדרם מציג מציין חסר.
- `tools/introduction_render.py`, `tools/private_storyreel.py`: כלי הרכבה קיימים, כפופים לשערי מקור, זכויות, קריינות ומדיה. FFmpeg אינו מחליף איורים מקוריים.
- `README.md`, `AGENTS.md` והמאגר הם מצב הפרויקט הציבורי־טכני; איורים, קולות וייחוסים פרטיים נשמרים **בנפרד**, עם בדיקות SHA-256, ולא מעלים אותם ל-GitHub הציבורי.

## דרישת המסירה ל-Codex או לכל מתכנת עתידי

**אסור למסור "אוטומציה גמורה" עד שאפשר לבצע את המשימות הרגילות ללא Codex, ללא סוכן AI אחר, ללא הרשאת GitHub כתיבה, וללא עריכת JSON ידנית.**

1. **כניסה אחת, פקודות יציבות:** להוסיף CLI יחיד ודטרמיניסטי הניתן להרצה עם Python בסביבת Windows או Linux, וכן כ-GitHub Actions על CPU. הפקודות הנדרשות: `doctor`, `plan`, `review`, `proof`, `run`, `resume`. רק אחר כך אפשר להוסיף כפתור אחד לממשק. כל פקודה תחזיר JSON עם `status`, `what_completed`, `blocked_reason`, `next_action`, `outputs`, `cost`. לא להמציא קבצים או קריינות.
2. **נתק את Codex:** המפעיל חייב לייבא ישירות את קוד Python הקיים או להפעיל אותו כתהליכים רגילים. אסור לקרוא ל-Codex API, ChatGPT, GitHub Copilot או כלי סוכן כדי לרוץ, לקבל החלטת תור, לבדוק cache, להרכיב וידאו או להמשיך אחרי ניתוק.
3. **מחשב GPU ניתן להחלפה:** קונפיגורציה `COMFY_ENDPOINT` דרך משתני סביבה או תצורת runtime פרטית, לעולם לא hard-coded לחשבון Codex/כתובת זמנית. ברירת מחדל: בדיקת מצב מקומית בלבד; שרת פרטי מרוחק רק לאחר אישור פרטיות והרשאות. הגדרות inference, מודלים, hash, זכויות ומגבלת משימות נשמרות בנפרד. אין הבטחה ל-GPU חינמי רציף.
4. **התאוששות ללא לחץ על המשתמש:** לפני יצירה שמור תור ותמונת מצב פרטית; אחרי מענה שרת שמור מזהה פעולה; אם ההרצה נקטעת, `resume` בודק מזהה ותוצר ולא מגיש בקשה נוספת אוטומטית כשמצבה לא ידוע. כשאין GPU, ממשיכים בביקורת, שמירה או עריכה של נכסים *שכבר קיימים*, ורושמים `BLOCKED_NO_GPU` עבור איורים חדשים. אין חיוב חלופי אוטומטי.
5. **שלמות וניידות:** קבצי מפרט, גרסאות Python, רשימת תלויות ורישיונות, workflow, תוצאות ביקורת ו-hashes נשמרים באופן שניתן לשחזור. גיבוי המידע הפרטי ב-Drive/אחסון פרטי והרשאות בעלים; הורדת/שחזור נכס מחייבים התאמת checksum. מחיקת סשן, החלפת GPU או הפסקת Codex לא אמורות לאבד תור או תוצר.
6. **בקרת תוצר:** איורים `CANDIDATE` אינם הופכים אוטומטית ל-`ACCEPTED`. אין לרנדר סרט "מאושר" ללא בדיקת תמונה מקורית, רציפות דמויות, קריינות תואמת, כתוביות, מקורות וזכויות. סקיצות מותרות בסימון ברור בלבד.
7. **עלות אפס כברירת מחדל:** שום מנוע בתשלום או העלאת מדיה פרטית לספק חיצוני לא יופעל אוטומטית. יש לאמת Zero-cost ועמידה בתנאי שימוש ברמת ההרצה, לא להסיק "חינם" מרישיון מודל. שימוש במכסת סביבת העבודה יישאר `unknown` אם אינו מדיד.

## מבחני קבלה שחייבים לעבור בלי Codex פעיל

- **CPU נקי:** `doctor` ו-`plan` פועלים ללא GPU/מפתחות/אינטרנט; אין תמונות מדומות, אין קריאת מודל, אין תשלום. `run` מחזיר חסם מדויק ולא נתקע.
- **ComfyUI מזויף:** שרת בדיקה מקומי עם PNG פיקטיבי מדמה העלאה, תור, הורדה ונפילה; ריצה שנייה `resume` לא מייצרת כפילות, לא מסמנת אישור שלא ניתן ומאמתת checksum.
- **החלפת ספק מחשוב:** לשנות endpoint בלבד, ללא שינוי שוט, בימוי או קובצי מקור, ולבדוק חיבור/תור במצב מורשה.
- **שחזור מאפס:** בסביבה חדשה, להריץ את כל הפקודות מן המדריך ולקבל אותו דוח מצב/אותם cache hits כאשר אותם נתונים פרטיים משוחזרים.
- **הרכבה עצמאית:** מהרגע שמסופקים נכסים *מאושרים* וקול תואם, `proof` יוצר MP4 וכתוביות דרך FFmpeg ללא AI, מאמת קודק, פריימים, קריאות RTL והיעדר גזירת סוף אודיו. כאשר חסרים נכסים, נותן דוח חסר ולא מחליף אותם בתוכן מומצא.

## מצב מציאותי ב-8.11.2026

התשתיות העצמאיות שפורטו בראש המסמך קיימות; CLI מאוחד עם `run/resume` והמבחנים המקיפים שלו **טרם מומשו**. אין כרגע GPU חינמי, רציף, מאומת ונגיש ישירות להרצת FLUX.2 Klein, ואין הבטחה שאפשר להפיק באופן בלתי מוגבל בלי מכסת שירות או מחשב מתאים. איורי OPN01–OPN07 טרם הושלמו ואושרו; OPN02 עדיין חסום לתיקון וקריינות N01/N02 חסרה. לא ניתן להצהיר "מערכת יצירת איורים חינמית פעילה" לפני יצירה אמיתית, בדיקת עלות, שמירת PNG תקין וביקורת רציפות.
