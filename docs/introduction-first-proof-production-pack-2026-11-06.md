# מבוא — חבילת ניסיון 60–90 שניות (ללא יצירה או חיוב)

**גרסת תכנון 1 · 6.11.2026 · סטטוס: PREPRODUCTION ONLY**

מטרה: להוכיח מסלול של תסריט מאושר → קריינות Alnilam מאושרת → 7 איורים מקוריים עקביים → כתוביות → FFmpeg → סרטון פרטי, **בלי תלות ב-Codex בהרצה השוטפת**. זו חבילה לסצנת הפתיחה `INTRO-A1-S01`, ולא שינוי ב-75 השניות הנפרדות של ברכות א׳ א׳. עדיין אין לסצנה זו קבצי דיבור/איורים/מוזיקה מאושרים; אין להציג זאת כסרט קיים.

## החלטות נעולות
- הקריין: `series-narrator-alnilam-continuous-v2`, ניסיון הרציפות הקודם שאהב בר; הניסיון המאוחר `בדיקת נוכחות עדינה בלבד` **נדחה כילדותי**. אין החלפת מודל, pitch, speed או פרופיל, ואין ניסוי TTS חדש במסגרת חבילה זו.
- הסגנון: רציני, בוגר, חכם, חם, בעל סמכות שקטה. רפרנס טנזן/קורה הוא לאופי דרמטי כללי בלבד, ללא חיקוי קול/מוזיקה/שוטים.
- התסריט: `scripts/introduction-working-draft.md` — `INTRO-A1-S01-N01` (74 מילים) ו-`N02` (35 מילים). אין לשכתב או להחליף טקסט בסתר. 109 מילים דורשות בקצב 105–135 מילים לדקה **כ-48–62 שניות דיבור בלבד**; כדי להגיע ל-60–90 שניות יש לתכנן מרווחי משמעות/פעולה ולהתאים למדידת WAV אמיתית, **לא להאריך תמונות ריקות**. אם הסרט המעניין קצר מ-60 שניות, אין לנפח אותו מלאכותית.
- מקור: `M01/M04` משמשים השראה רעיונית למסירה, **לא** ראיה לשני נוסעים מסוימים. בכל חומר ביקורת: `המחזה סמלית — לא אירוע היסטורי מתועד`.
- אין כתיבה/פרסום/תשלום/הרצת API בלי שערי אישור, ואין יצירת טקסט בתוך איור.

## רצף הפקה עצמאי מבוקש (לא טענה שכבר מומש)
1. **READ ONLY:** סריקת `INTRO-A1-S01-N01/N02`, אימות מקור/טקסט/גרסה, חישוב dry-run של 7 איורים ו-2 קטעי קריינות; אם חסרים → `BLOCKED_MISSING_REAL_MEDIA` עם רשימה מדויקת. אין API בשלב זה.
2. **קליטת נכסים:** קול WAV אמיתי מהפרופיל המוגן, שבעה איורים מאושרים עם hash ורישיון, כתוביות תואמות להקלטה. לא להשתמש בטייק האודישן הישן כקריינות לטקסט חדש.
3. **מניפסט:** לכל shot מספר פריימים שלם ב-24fps; לכל WAV התחלה/אורך בדגימות 48kHz; 2,000 דגימות לפריים; מסלול קובץ נפרד לכתוביות, אווירה ומוזיקה. אין להמציא זמני קריינות לפני שיש WAV.
4. **הרכבה:** FFmpeg דרך הכלי הקיים או הרחבה מצומצמת שלו, קובץ MP4 פרטי, SRT/VTT, תיעוד גרסת מניפסט ו-hash. כשל בקליפ אחד לא מייצר מחדש את שאר הנכסים.
5. **QA:** ארבע צפיות נפרדות: ללא שמע, שמע בלבד, רציפות, מתחיל בלימוד. בודקים במיוחד שאין גוון ילדותי, שאין מעבר דובר, שכתב המקור לא מעורבב עם המחזה ושאין שימוש בחומר לא מורשה.
6. **מבחן עצמאות:** אחרי ניסיון אחד מוצלח, הרצה חוזרת מאותו מניפסט **בלי Codex ובלי קריאות API נוספות** צריכה לתת אותו תוצר או cache hit מאומת. רק אז ניתן לומר שהרכבת סרט הניסיון עצמאית. הפקת נכסים חדשים עדיין תלויה במודל/משאבים/הרשאות.

## חסמים ידועים
- שני קטעי N01/N02 **לא הוקלטו**; 49 שניות Alnilam הקודמות הן טקסט אחר ואסור לשבץ אותן.
- שבעת איורי OPN **אינם קיימים כנכסים מאושרים**; איורי SH09 הישנים אינם תחליף.
- תחקיר חזותי של התקופה, רישיונות, כתוביות וקורא תורני עדיין פתוחים; אין לשנות flags במניפסט.
- מנוע `tools/private_proof_assembler.py` מיועד כרגע ל-16 שוטים/75 שניות של `berakhot-01-01`, **לא** לסצנת המבוא. יש להרחיבו/להכלילו בזהירות ולא לשנות את חוזה הניסוי הקודם. אין כרגע renderer מוכח למבוא.
- שימוש בתשתית קול/תמונה של צד שלישי עשוי לצרוך מכסה גם ללא חיוב חיצוני; יש לאמת לפני כל הרצה.

**השלב הבא בהנדסה:** להוסיף validator/dry-run נפרד ל-`INTRO-A1-S01` עם בדיקות יחידה (חסרים, hash, זכויות, אי-שימוש בטייק שנדחה, זמנים, cache), ואז לחבר אותו למרכיב הווידאו הקיים בלי לפגוע בניסוי ברכות. לאחר מכן להביא לאישור תחקיר חזותי ו-7 איורים לפני יצירה. בר אינו נדרש לבצע עריכה ידנית.
