# מסלול GPU חינמי — הנחיות טכניות לאחר ניסוי SH01 מוצלח

**סטטוס מהחדר הראשי:** [README.md](../README.md). **SH01 כבר נוצר ב-Colab, נפתח ונבדק**. [רישום הניסוי](../episodes/berakhot-01-01/trials.json). אין לשלוח את בר לבצע שוב את ניסוי SH01. התמונה אינה מאושרת אמנותית.

עדכון: 31.10.2026. **מטרת המסמך:** לשמור את ההבדל בין חינמי באמת, מכסה חינמית, ומודל בקוד פתוח שעדיין דורש מחשוב. אין להשתמש בכלי התמונות של ChatGPT לצורך הפקת הסדרה אלא לפי בקשה חדשה מפורשת. אין לרכוש מנוי או קרדיטים או להפעיל שירות GPU בתשלום.

## בחירה מעשית: מחברת Colab ב-GPU חינמי, SDXL כבסיס ניסיון

**[פתיחה ישירה של מחברת אולפן המשנה ב-Colab](https://colab.research.google.com/github/barkinam21-pixel/project-mishna/blob/main/notebooks/free_mishnah_images_colab.ipynb)**

1. בדפדפן בנייד פותחים את הקישור (חשבון Google, אם תידרש כניסה). אם לא נבחר GPU כברירת מחדל: **Runtime → Change runtime type → GPU**, למשל T4. השימוש ב-GPU חינמי מותנה בזמינות ובמכסות המשתנות של Colab. אל תבחר תוכנית בתשלום.
2. **Runtime → Run all**. ברירת המחדל: **תמונת מבחן אחת** (SH01). אפשר לבחור 5 איורי מקור נפרדים לסצנת הבנים, או את 16 השוטים המתוכננים — **רק לאחר אישור סגנון התמונה הראשונה**.
3. מתקבל ZIP ובו PNG לכל שוט, רישום פעולות JSONL, צילום גרסה של חבילת פרומפטים ו-SHA-256 לכל תמונה. בהגדרות ברירת המחדל מופיע חלון הורדה אוטומטי; אם הדפדפן חוסם אותו יש קישור להורדה בתוך המחברת.
4. אין התקנה ב-Windows, אין מפתח API, אין הרשמה לתשלום, ואין קריאה לשירות גנרטיבי בתשלום מהקוד. **פעולת GPU עדיין צורכת את מכסת השירות**. אם יש לחשבון Google מנוי Colab בתשלום, יש לוודא שלא משתמשים במכסת קרדיטים בתשלום.

**מה בחרנו טכנית:** `stabilityai/stable-diffusion-xl-base-1.0` ב-Hugging Face, ברישיון **CreativeML Open RAIL++-M** (לא Apache, לא Public Domain), דרך `diffusers`, בדגם GPU T4/P100 כאשר זמין. הגודל המתוכנן לניסוי 1024×576; תוצאה עדיין אינה בהכרח ברמה המתאימה לפרק. המודל ייטען **רק לאחר** בדיקת GPU. בכל יצירה חדשה תהיה תמונת מקור נפרדת, לא crop של תמונה אחת.

[כרטיס ורישיון המודל](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0) · [שאלות ותשובות Colab הרשמיות](https://research.google.com/colaboratory/faq.html).

## אפשרות מיידית ליצירת תמונה אחת: Hugging Face ZeroGPU

**[דמו FLUX.2 Klein 4B של Black Forest Labs](https://huggingface.co/spaces/black-forest-labs/FLUX.2-klein-4B)** — במועד הבדיקה הדמו מסומן `Running on Zero` ומשתמש ב-GPU חינמי משותף. המודל עצמו שוחרר ברישיון Apache 2.0; חשוב להבחין בין רישיון המודל ובין המכסה החינמית בשרת. אפשר להעתיק פרומפט מה[חבילה הממוספרת](../episodes/berakhot-01-01/free-cloud-image-prompts.json) ולהדביק בדמו לצורך ניסיון. **אין הבטחה שהתמונה מתקבלת או שהדמו זמין בכל רגע**; לא הרצנו קריאת GPU מתוך חיבור ChatGPT.

- מסמך [Hugging Face ZeroGPU הרשמי](https://huggingface.co/docs/hub/spaces-zerogpu): משתמש חינמי מחובר מקבל 5 דקות GPU ביום, לא מחובר 2 דקות; המכסה מתאפסת 24 שעות מהשימוש הראשון. במקרה של חשבון בתשלום קיימת אפשרות חריגה למכסה בתוספת קרדיטים — **אין להפעיל חיובים**.
- אם יידרש בהמשך עיצוב אחיד או שליטה במספר תמונות, מחברת Colab רצה על GPU של החשבון, ואפשר לשלב בעתיד מודל multi-reference כמו FLUX.2 Klein 4B **רק אחרי ניסוי תואם VRAM** ולא רק בגלל הבטחה שיווקית.
- [מידע רשמי על FLUX.2 Klein 4B](https://bfl.ai/models/flux-2-klein): 4B תחת Apache 2.0; גרסת 9B אינה באותו רישיון.

## חלופה כאשר Colab בלי GPU: Kaggle

- [התיעוד הרשמי](https://www.kaggle.com/docs/notebooks): Kaggle Notebooks מציע GPU חינמי כגון NVIDIA P100, כפוף לזמינות ולתור; שימוש בענן.
- [מגבלת GPU המתועדת](https://www.kaggle.com/docs/efficient-gpu-usage): סביב 30 שעות GPU בשבוע (לעיתים יותר, בהתאם לביקוש/זכאות); אין התחייבות אישית למכסה או לשירות רציף.
- אפשר לייבא את אותה מחברת `.ipynb` מ-GitHub לקאגל ולאפשר GPU. יש לבדוק הרשאות רשת בגישת המחברת להורדת מודל. **לא אימתנו הפעלה מלאה ב-Kaggle**; Colab קודם לצמצום צעדים.

## מגבלות ופרטיות
- **מכלול המחשוב אינו "בחינם ללא הגבלה"**: קיימות מכסות שירות, תורים וניתוקים; אין התחייבות להפקה אוטונומית ברקע.
- ללא התחברות לחשבון Colab/Space של המשתמש, ל-ChatGPT **אין גישה להקצאת GPU החינמית שלו** ואינו יכול להבטיח שהתמונה נוצרה. הקוד נכתב ונבדק ברמת מבנה/סינטקס ב-GitHub Actions; **אומת ניסוי SH01 אחד מהארכיון שהעלה המשתמש; לא אומת ניסוי עקביות או סרט**.
- קבצי Colab נמחקים כשמכונת הענן מתנתקת; לכן יש הורדת ZIP, והרישום נארז מחדש לאחר כל תמונה. אם בוטלה ההרצה לפני השלמתה, יש להוריד את ה-ZIP שכבר קיים באותה מכונה.
- אין העתקה של כתב יד קאופמן המצולם או כל חומר ברישיון מוגבל. האיורים הם שחזורים אמנותיים מקוריים עם תווית סטטוס `unreviewed_visual_reconstruction`.
- לפני שילוב בסרט: מחקר נוסח ותיקון גרסאות `חייבין/מותרין`, ביקורת תורנית אנושית, אישור סגנון, עקביות הדמויות וזכויות נכסים. התסריט, המניפסט והפרסום נשארים חסומים.
