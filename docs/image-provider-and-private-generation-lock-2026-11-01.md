# כלל מחייב — ספק יצירת התמונות והוצאות | קולנוע המשנה

**נקבע לפי הוראת המשתמש מ־1 בנובמבר 2026:** תמונות חדשות לסדרת "קולנוע המשנה" **לא ייווצרו באמצעות ImageGen / יצירת תמונות בתוך ChatGPT**. היצירה תתבצע רק במסלול החיצוני שכבר נרכש וחובר לפרויקט. המסלול שבוצע ואומת בפרויקט הוא **fal.ai**, מודל `fal-ai/flux-2-pro`, דרך GitHub והגדרות פרטיות. אם הקשר לספק אחר ישתנה, יש לתעד את השינוי במקום לנחש.

## פירוט החלטות שאסור לשכוח
- **צילומי הפרויקט נשארים פרטיים.** אין להוסיף קבצי תמונות, תמונות ייחוס, אישורי תשלום, מפתחות API, קישורים חתומים או סרטונים לקוד ציבורי ב-GitHub.
- **אין יצירה נוספת דרך ChatGPT.** כלי ChatGPT מותרים למחקר, תסריט, בימוי, פרומפטים, אימות, עיבוד תמונות קיימות מקומית, כתוביות, עריכה, אוטומציה וקוד בלבד.
- **העובדה שיש יתרת קרדיטים שכבר נרכשה אינה אישור לביצוע קריאת API נוספת בתשלום.** בקשת אישור ספציפית היא תנאי לביצוע; עלות קרדיטים/שערי תמחור ומצב היתרה אינם ניתנים להסיק מן הקוד בלבד.
- פרומפטים חדשים מאוחסנים ב-`episodes/berakhot-01-01/fal-prepaid-shotpack-v1.json` במצב `dry_run_prompts_only`; בכל 16 השוטים `asset_status=not_generated` ו-`visual_approval=false`.
- בזמן הפקה מאושרת: קודם חבילת דמויות/סטים פרטית, אחריה איורים מקוריים נפרדים לסצנות; בדיקה של הראשון לפני ריצה סדרתית. מזהה מודל, seed אם הוחזר, קישורי זכויות, שעות, SHA-256, חיוב ויעילות נרשמים **בתיק פרטי**, לא בקוד הפומבי.
- **SH09 ו-S01 הדגמות קודמות אינן תמונות מוכנות לפרסום:** הראשונה קיבלה בחינת תנועה/סגנון אך יש בה בעיית blocking ופרטים היסטוריים; השנייה נוצרה בעבר בצ'אט לפני ההנחיה החדשה ומותרת כייחוס חזותי פרטי בלבד, לא נכס ייצור מקובל.
- מהירות V10 היא נקודת ייחוס זמנית לצילום חלק; הצבעים מעט דהויים ודרמטיים יותר, ללא רעד/רטט לכל אורך הפרויקט.

## מסלול המשלוח
1. מקורות -> הגדרת סצנה -> continuity sheets -> פקודות יצירה ייעודיות לספק החיצוני -> יצירה פרטית באישור -> קבלה/פסילה בנפרד -> קריינות וכתוביות -> הרכבת proof.
2. לפני ריצה קוראים `tools/validate_external_shotpack.py` — preflight לקריאה בלבד, **לעולם לא** יוצר תמונה ולא שולח בקשת תשלום.
3. הפקה אוטומטית ברקע מחייבת תשתית מתוזמנת מאושרת ומגבלת תקציב; אין לטעון ש־GitHub Actions או ChatGPT ממשיכים לעבוד ללא הרצה פעילה.

**אישורי מקור, זכויות, קריינות ופרסום עדיין נחוצים בנפרד.** אישור האופי האמנותי אינו אישור לציטוט או לזיהוי היסטורי.
