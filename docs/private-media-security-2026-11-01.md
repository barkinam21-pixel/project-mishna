# קולנוע המשנה — הגנת תמונות פרטיות ב-GitHub ציבורי (2026-11-01)

**החלטת משתמש:** אין יצירת תמונות חדשות ב-ChatGPT; יש להשתמש ב-fal.ai הקיים, באישור נפרד לפני כל חיוב. כל קובצי האמנות והייחוס פרטיים. מאגר `barkinam21-pixel/project-mishna` הוא ציבורי — **קוד כן, תמונות מקוריות לא**.

## ממצא אבטחה מתוקן
- תוצרי GitHub Actions של מאגר ציבורי עשויים להיות נגישים לבעלי גישת קריאה למאגר. לא ניתן להתייחס ל-`actions/upload-artifact` כחסימה של גישה לאיורים גולמיים.
- ה-Pilot הישן SH09 העלה Artifacts ללא הצפנה; הנתיב הישן `.github/workflows/fal-sh09-manual.yml` הושבת.
- התמונה המקורית והגרסה המדורגת גובו ואומתו לפני סגירה של ארטיפקט ישן. ספריית גיבוי פרטית: `/Mishnah Project/private-SH09-2026-11-01`.
- **אין הבטחה שאפשר לבטל עותקים שכבר הורדו מן הארטיפקט הישן**; צמצום החשיפה בעתיד אינו מחיקה רטרואקטיבית של כל עותק.

## זרימת עבודה בטוחה חדשה
1. בקשה בודדת `fal-ai/flux-2-pro` מותרת רק באמצעות workflow ייעודי עם `workflow_dispatch` ו-`confirm_paid=YES`; ברירת המחדל `NO`.
2. תכנון payload לפי תיעוד fal הרשמי ב-`tools/fal_payload_preflight.py`; אין `negative_prompt` עצמאי בממשק T2I, לכן נכתב כחלק מן `prompt`.
3. תוצאה נשמרת **מקומית זמנית ב-GitHub runner**: PNG, receipt, usage state; URL התוצאה והמפתח אינם נכתבים ל-log.
4. לפני ה-`upload-artifact`, `tools/seal_private_media.py` אורז את הנכסים ומצפין ב-AES-256-GCM, עם מפתח חד־פעמי עטוף RSA-OAEP-SHA256 (מפתח ציבורי 3072 ביטים).
5. ל-GitHub מועלה **קובץ מוצפן בלבד** `.bin`, בלי PNG, בלי zip מקורי ובלי רשומת חיוב חשופה.
6. מפתח ההצפנה הציבורי: `security/production_artifacts_public_key.pem` במאגר הציבורי.
7. **מפתח הפענוח הפרטי אינו ב-GitHub, אינו בלוגים ואינו נשלח לשירות fal**; גיבוי: ChatGPT Library `/Mishnah Project/private-production-keys-2026-11-01/production_artifacts_private_key.pem`. משתמשים בו רק לפענוח חומר מוצפן במסגרת סביבת עבודה פרטית.
8. שמירת תוצר סופי: ChatGPT Library פרטית (לא ב-GitHub). בדיקת תקינות והחזרים לפי SHA256; אפשר להריץ `seal_private_media.py unseal` כאשר המפתח הפרטי נגיש בסביבת עבודה מאובטחת.

## בדיקות
- AES-GCM דוחה ביט יחיד ששונה בקובץ.
- RSA פרטי שגוי נדחה; אין כתיבה מוקדמת של תמונות לפני אימות.
- שמות נתיב `../`, קישורים סימבוליים וערכים כפולים נדחים.
- בדיקת round trip של PNG אמיתי מצאה SHA256 זהה למקור.
- בדיקות offline; קובצי סטוריבורד ו-16 פרומפטים אינם קריאות ל-fal.

## גבולות ואי-הבטחות
- הספק fal.ai עצמו מעבד את הבקשה ויכול לאחסן תוצר לפי תנאיו. ההצפנה מגינה על **ארטיפקט ההעברה ב-GitHub**; היא אינה מונעת מהספק עצמו גישה במהלך העיבוד.
- מגבלת תקציב מקומית אינה הבטחה של **provider-side hard cap**; נדרשים אישור ידני יחיד, רישום מראש, ללא retries ומעקב בחשבון הספק.
- אישור סגנון/קרדיטים **אינו** אישור מקורות/זכויות/פרסום. מקור `חייבין/מותרין` עדיין נדרש להכרעה לפני קריינות של ציטוט מדויק.
- אם מפתח הפענוח נמחק או אבד, התוצרים המוצפנים עלולים להיות בלתי ניתנים לשחזור; יש לשמור את גיבוי המפתח הפרטי בחשבון המשתמש.
- לא לשתף את קובץ המפתח הפרטי, ולא לצטט אותו במסמכי project.
