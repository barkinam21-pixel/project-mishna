# חלופות זולות ל-Higgsfield — סקירת קוד פתוח ואפשרויות ענן
תאריך סקירה: 2026-10-31 | שלב: **מחקר בלבד, לא ניסוי איכות ולא חיבור GPU**

## ההחלטה למיזם
**לא לקנות מנוי Higgsfield כרגע.** המנגנון הזול ביותר לפרקים מאוירים הוא:
1. רוב השוטים: איורים מקוריים *שאושרו*, פריים נעול או תנועת מצלמה מתונה, הרכבה ב-FFmpeg בחומרה רגילה בענן.
2. מספר קטן של *שוטי גיבור*: image-to-video ממודל פתוח, אחרי אישור מראה וקול.
3. להפעיל GPU לפי צורך מדוד ולא לשכור שרת קבוע. **כל שימוש בתשלום דורש אישור מפורש ומגבלת תקציב.**

זה אינו מבטיח שמנוע פתוח יהיה יפה יותר מ-Higgsfield. דרוש *מבחן 2 קליפים קצרים מאותה תמונה ואותו תיאור*, מדדי רציפות דמות, יציבות ידיים/פנים, איכות תנועה, זמן, מחיר ויכולת לשחזר תוצאה.

| [LTX-2 / LTX-2.5](https://github.com/Lightricks/LTX-2) | תלוי מודל ותצורה; LTX Desktop מציין **24GB VRAM ו-32GB RAM** לפחות | כן, גם סאונד | [רישיון קהילתי](https://github.com/Lightricks/LTX-2/blob/main/LICENSE-2_x) עם מגבלות וחובת הסכם מסחרי בגופים עם >=$10M הכנסות שנתיות | מעניין מאוד להפקה המשלבת קול/וידאו, אך לא כלי חינמי פשוט בענן; לשלב מבחן מאוחר יותר בלבד |

**לא לפתח למחשב של בר:** Windows 10, 8GB RAM, כאבים בידיים; דרישת GPU/זיכרון של התוכנות אינה מעשית עבורו. גם תוכנת LTX Desktop המקומית אינה פתרון מתאים לחומרה הזאת.

## כמה תעלה הרצה באמת?
הקוד והמשקולות *יכולים להיות זמינים ללא תשלום רישיון אישי*, אבל **GPU, דיסק, תעבורה וזמן טעינה** עשויים לעלות כסף. אין להמיר מחיר לשעה במחיר לסרטון בלי בדיקת זמן יצירה בפועל (כולל הורדות, חימום, ניסיון כושל ופלט).

- [Vast.ai GPU live pricing](https://vast.ai/pricing) — מחירי שוק משתנים; [דף מדריך רשמי מ-22.7.2026](https://vast.ai/article/how-much-does-it-cost-to-rent-a-gpu-in-the-cloud-live-pricing-guide) מציג RTX 4090 מ-$0.14/שעה ומחיר חציוני כ-$0.54/שעה *בעת קריאת הדף*, לא מחיר מובטח, ואולי יש עוד חיובי אחסון/תעבורה.
- [Runpod Pricing](https://www.runpod.io/pricing) — יש סוגי תמחור שונים; במודל Serverless GPU-4090 תועד ~$1.34/שעה ו-L4/3090 ~$0.75/שעה בשעת הסקירה. זה אינו מחיר קבוע לכל תצורת Pod, לא כולל עלויות אפשריות אחרות.
- [Google Colab FAQ](https://research.google.com/colaboratory/faq.html) — הגרסה החינמית *אינה מבטיחה GPU*; המכסות משתנות. אין לבסס עליה אולפן אוטומטי רציף.
- [Higgsfield official pricing](https://higgsfield.ai/pricing) — מסלולי מנוי/קרדיטים משתנים; יש גם יצירות חינם מוגבלות. השוואה אמיתית דורשת את עלות הקרדיטים לשוט נבחר, לא רק מחיר המנוי. **לא הוכח** שהחלופות הזולות טובות ממנו באיכות.

## הגנה מפני בלבול בהגדרות 'חינם'
- GitHub Actions אינו GPU וידאו חינמי. התשתית הנוכחית מפיקה *דוחות מקור ותקציב בלבד*.
- רישיון קוד Apache אינו בהכרח רישיון **weights**, נתונים, יצירה מסחרית או הגבלת מדינות.
- תנאי HunyuanVideo-1.5 מחייבים עיון נפרד: שימוש/הפצה באיחוד האירופי, בריטניה ובדרום קוריאה מוחרגים, ועלולים להיות בעייתיים אם האתר מפיץ אליהן.
- לא להפעיל סשן GPU ולא לחבר API בתשלום ללא אישור בר. לא לשמור סודות API בגיטהאב ציבורי.
- אין לבזבז קרדיטים על סרטים שלמים לפני אישור *סצנה אחת*; את שאר הסרט להרכיב מאיורים מקוריים ו-FFmpeg.

## מדידת פיילוט כשיגיע שלב יצירת נכסים
באותה תמונה מאושרת, אותה תנועה ותאורה, לייצר **עד שני קליפים בני 3–5 שניות** בכל מנוע מאושר בתקציב. לרשום:
- 1–5: רציפות דמות, פנים/ידיים, בימוי, בוהק והולם מקור;
- זמן המתנה והפקה, משך קליפ נטו, שימוש GPU ב-`h`, חיוב `USD`, פלט תקין;
- נסיונות כושלים ומדדי שיפור מול תמונה סטטית;
- **סטטוס:** `not_tested`, `tested_rejected`, `tested_candidate`, `approved`.

בחירה ראשונית למבחן עתידי: **Wan2.2 TI2V-5B** אם יש שרת GPU 24GB במחיר מאושר; **HunyuanVideo-1.5** כחלופה קלה יותר בכפוף לרישיון; **FramePack** כניסוי רק כשזמן GPU אינו יקר. לא נבחר ספק GPU בשלב המחקר.
