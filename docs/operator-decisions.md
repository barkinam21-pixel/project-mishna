# החלטות הפעלה קבועות — אולפן המשנה

תאריך עדכון: 31.10.2026

## קלות שימוש
- בעל הפרויקט רוצה שהמערכת תיעשה ככל האפשר על ידי ChatGPT ו-GitHub, עם **אפס התקנות מקומיות** כברירת מחדל.
- אין לבקש ממנו להדביק לוגים, להריץ פקודות, לערוך סרטים, או למסור שוב פרטים שכבר קיימים במאגר.
- כל בדיקה חשובה צריכה להיות מאומתת מול **תוצאה אמיתית**: ממצאי מקור, בדיקת CI, ובשלב ההפקה גם צפייה בסרט ולא רק הצלחת רנדר.

## Codex — הנחיית ההפעלה של בר
- **Codex אינו הכרחי**; כרגע אפשר להתקדם דרך מחקר וכלי GitHub מחוברים.
- כאשר נדרשת עבודת קידוד מסובכת על מספר קבצים יחד, חיבור FFmpeg/ComfyUI/שרת GPU, בדיקות או ניפוי שגיאות שלא ניתן לבצע בנוחות ובבטחה דרך GitHub המחובר, יש לשקול שימוש ב-Codex דרך הדפדפן בטלפון.
- **כשהוא באמת נחוץ**, יש לכתוב לבר בצורה **בולטת וברורה**: `🔔 עכשיו כדאי להשתמש ב-Codex` ולהוסיף פעולה אחת קצרה ומדויקת כולל קישור `https://chatgpt.com/codex` או קישור רלוונטי מעודכן. לא לטעון שהוא חובה אם אפשר בלי.
- Codex עלול להיות מוגבל במכסה; אין להקפיא את הפרויקט בגללו. אפשר להמשיך במחקר וב-GitHub עד שהוא זמין.
- אל תשלח התראת Codex מוקדמת רק מפני שהשם הוזכר; צריך צורך ממשי ונתיב פעולה ישים.

## שער ההתקדמות
- שלב נוכחי: **תיק מקורות** (Stage 2), לאחר תשתית האוטומציה הבסיסית.
- השוואת שלוש מהדורות משנה ברכות א, א עברה מול Sefaria API בשעה 06:45 UTC של 31.10.2026; לא בוצעה עדיין נעילת נוסח או אישור קורא תורני.
- אין להתקדם לכתיבת תסריט/הפקת תמונות ללא תיעוד והשלמת אישורים הנדרשים לשלבים הללו.
- תקציב הוצאה דרך שירותי AI חיצוניים: **$0 מאושר**. צריכת שימוש/מכסות GitHub או ChatGPT שאינה נראית נשארת unknown, לא אפס.
- פיילוט עתידי 60–90 שניות. קוד פתוח בענן קודם לתוכנות כבדות במחשב.
