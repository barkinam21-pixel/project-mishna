# החלטות הפעלה קבועות — אולפן המשנה

תאריך עדכון: 31.10.2026

## קלות שימוש
- בעל הפרויקט רוצה שהמערכת תיעשה ככל האפשר על ידי ChatGPT ו-GitHub, עם **אפס התקנות מקומיות** כברירת מחדל.
- אין לבקש ממנו להדביק לוגים, להריץ פקודות, לערוך סרטים, או למסור שוב פרטים שכבר קיימים במאגר.
- כל בדיקה חשובה צריכה להיות מאומתת מול **תוצאה אמיתית**: ממצאי מקור, בדיקת CI, ובשלב ההפקה גם צפייה בסרט ולא רק הצלחת רנדר.

## כלל חדש: הפקת תמונות מחוץ ל-ChatGPT (אושר 31.10.2026)
- בר חזר והדגיש: **הסיבה להקמת אולפן חיצוני היא לא לבזבז את מכסת התמונות של ChatGPT**. לכן אין להפעיל `image_gen` או כלי יצירת תמונות של ChatGPT עבור פרויקט המשנה בלי בקשה מפורשת חדשה.
- להשתמש תחילה ב-GPU חינמי בענן (Colab free / Hugging Face ZeroGPU / Kaggle בהתאם לזמינות), ולבחון כמות ואיכות מול מכסת השירות. אין להגדיר תוכנה בקוד פתוח כשרת GPU חינמי ללא בדיקה.
- מחברת Colab, פרומפטים מסומנים, ZIP ורישום שימוש: [התיעוד](free-cloud-gpu-images.md), [מחברת ישירה](https://colab.research.google.com/github/barkinam21-pixel/project-mishna/blob/main/notebooks/free_mishnah_images_colab.ipynb).
- שמירה: בלי התקנות ב-Windows ובלי פקודות למשתמש. **נדרש חיבור משתמש ל-GPU החינמי שלו כדי להפיק תמונה אמיתית**; אין להציג בדיקת קוד GitHub כאילו נוצרה תמונה.
- גבולות: שירותי GPU חינמיים מוגבלים; אם אין משאב חינמי אל תפעיל GPU בתשלום ואל תדרוש כרטיס אשראי. הוצאות חיצוניות מאושרות: $0. שימוש בפועל ובמכסה לא ידוע עד בדיקת חשבון/הרצה.
- עקביות, זכויות ואישור תורני נשארים שערי הפקה. ניסיון חזותי פרטי אינו נעילת נוסח או הפצה.

## Codex — הנחיית ההפעלה של בר
- **Codex אינו הכרחי**; כרגע אפשר להתקדם דרך מחקר וכלי GitHub מחוברים.
- כאשר נדרשת עבודת קידוד מסובכת על מספר קבצים יחד, חיבור FFmpeg/ComfyUI/שרת GPU, בדיקות או ניפוי שגיאות שלא ניתן לבצע בנוחות ובבטחה דרך GitHub המחובר, יש לשקול שימוש ב-Codex דרך הדפדפן בטלפון.
- **כשהוא באמת נחוץ**, יש לכתוב לבר בצורה **בולטת וברורה**: `🔔 עכשיו כדאי להשתמש ב-Codex` ולהוסיף פעולה אחת קצרה ומדויקת כולל קישור `https://chatgpt.com/codex` או קישור רלוונטי מעודכן. לא לטעון שהוא חובה אם אפשר בלי.
- Codex עלול להיות מוגבל במכסה; אין להקפיא את הפרויקט בגללו. אפשר להמשיך במחקר וב-GitHub עד שהוא זמין.
- אל תשלח התראת Codex מוקדמת רק מפני שהשם הוזכר; צריך צורך ממשי ונתיב פעולה ישים.
