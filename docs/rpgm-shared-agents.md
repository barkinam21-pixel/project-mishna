# RPG Maker — פרויקט נפרד, אותם סוכנים

**מטרה:** לבדוק ולבנות אוטומציית משחק RPG Maker אמיתית (ניווט, NPC, משימות, בחירות) ולא רק מקרו או הליכה מובנית.

## מבנה
- מאגר GitHub עצמאי בשם `rpg-maker-auto-player`.
- אותו חשבון Copilot ואותו צוות כלי AI משמשים גם את פרויקט המשנה; כל משימה נשלחת למאגר המתאים.
- אין להעביר קוד משחק, קבצי שמירה, תוכן פרטי או חומרים מוגני זכויות למאגר ציבורי בלי בדיקת הרשאות.
- להתחיל בבדיקת היתכנות אמיתית במשחק מתאים; לשמור וידאו/לוגים ומדדי הצלחה. לא לטעון להצלחה בלי מבחן.
- הוצאות חדשות דורשות אישור; התקרה הכוללת היא $60 בחודש כולל Copilot.

## צעד יחיד מהטלפון
1. פתח את [GitHub New Repository](https://github.com/new?name=rpg-maker-auto-player).
2. בחר **Private**, השאר את השם, בחר **Add a README**, ולחץ **Create repository**.
3. לאחר מכן נחבר את קישור המאגר לתפריט הראשי ונעתיק אליו הנחיות לסוכן.

הפרדה זו מונעת שינוי בטעות של סרטי המשנה כאשר מתקנים משחק.
